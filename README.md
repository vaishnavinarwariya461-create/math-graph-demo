# 🎓 Math Interview Demonstration App

An interactive, single-page **math teaching and interview demonstration tool** built with **HTML, Tailwind CSS, and Vanilla JavaScript**.

This project is designed to showcase **conceptual clarity, real-time explanation skills, and visual intuition**, especially for **math teaching interviews (e.g., Cuemath-style demos)**.

---

## 🔗 Live Demo

👉 https://vaishnavinarwariya461-create.github.io/math-graph-demo/

---

## ✨ Features

- 🧮 **Interactive Graphing Engine**
  - Hover to inspect function values
  - Real-time plotting using HTML Canvas

- ✍️ **Hybrid Editor**
  - Type explanations and draw simultaneously
  - Freehand drawing with eraser and clear tools

- 📐 **Preloaded Math Problems**
  - Vertical tangents & inflection points
  - Rational and absolute value functions

- 🎲 **Random Function Challenge**
  - Auto-generates functions
  - Includes derivative-based analysis

- 🖥 **Fullscreen & App Mode**
  - Editor fullscreen
  - Global app-like fullscreen mode

- 📱 **Responsive Design**
  - Optimized for desktop, tablet, and mobile

---

## 🛠 Tech Stack

- **HTML5**
- **Tailwind CSS (CDN)**
- **Vanilla JavaScript**
- **HTML Canvas API**

_No frameworks. No backend. Single-file architecture._
